# ggen Parity Register

Standing: PARTIAL

Frontmatter parity between ggen (`crates/ggen-engine/src/template.rs`) and igniter, generated by
`mix ggen_igniter.parity` (fail-closed: a Rust field absent from `GgenIgniter.Frontmatter` exits 1;
absent ggen checkout prints `[SKIP]`). Consumers: `pack_sync` = `GgenIgniter.PackFrontmatter.Sync`;
`mix_sync` = `mix ggen_igniter.sync` only; `declared` = mirrored, no consumer (registered
divergence; pack-sync refuses it loudly with `REFUSED:UNSUPPORTED_FRONTMATTER`); `internal` =
pipeline-set by ggen, never authored.
