# Authority Manifest — ggen_igniter factory cell

Allowed without asking: edit repo files, create tests/fixtures, run builds/tests,
create local commits, clean test-owned temp state, modify generated test apps.

Forbidden without explicit user authority: force push, publish Hex release,
delete remote branches, merge external PRs, rewrite public history, delete
unrelated user data, destroy uncommitted preexisting work (git reset --hard /
git clean -fd / git checkout -- . against a dirty worktree are never used).
